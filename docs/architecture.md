# System Architecture

## Overview

The Python Simple Calculator is a simple command-line application.

## Components

1. **User Interface**
   - Accepts numbers and arithmetic operations from the user.

2. **Calculator Logic**
   - Performs addition, subtraction, multiplication, and division.

3. **Test Module**
   - Tests the calculator functions to make sure they work correctly.

## Flow

User Input → Calculator Logic → Result

## Project Structure

- `simple_calculator.py` – Main calculator program
- `tests/test_calculator.py` – Unit tests
- `docs/architecture.md` – System architecture documentation
- `README.md` – Project information
