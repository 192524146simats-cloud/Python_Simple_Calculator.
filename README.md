# 🧮 Python Simple Calculator

A beginner-friendly command-line calculator built using Python. This project performs basic arithmetic operations such as **Addition, Subtraction, Multiplication, and Division**.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 📥 User input through the terminal
* ⚡ Instant result display

## 🛠️ Technologies Used

* **Python 3**

## 📂 Project Structure

```text
Python_Simple_Calculator/
│── simple_calculator.py
└── README.md
```

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/vaishnavi-142006/Python_Simple_Calculator.git
```

2. Open the project folder:

```bash
cd Python_Simple_Calculator
```

3. Run the program:

```bash
python simple_calculator.py
```

## 📸 Sample Output

```text
Enter first number: 10
Enter second number: 5

Choose operation:
1. Addition
2. Subtraction
3. Multiplication
4. Division

Enter choice: 1

Result: 15
```
